# ProjectX

## Environment
- Unity 2022.3 LTS
- C#
- Target Platform: PC / Mobile

## Overview
실시간 전투 + 그리드 기반 시스템을 가진 프로젝트의
핵심 로직만 발췌한 코드입니다.

## Key Systems
- GameEntity 기반 아키텍처
- 전투 / 장비 / 애니메이션 종속성 분리
- Grid A* 경로 탐색 최적화
- Tick 기반 행동 시스템

## Highlighted Code
- Scripts/GameEntity/
- Scripts/Combat/
- Scripts/Grid/

## Design Focus
- 의존성 역전
- 테스트 가능한 구조
- 런타임 성능 고려
